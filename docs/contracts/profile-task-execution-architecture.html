Ruang Office: Profile-Directed Task Execution Architecture

End-to-end task dispatch, parameterization security, and bidirectional state synchronization

Security & Isolation

  • • Strict execFile argument array parameterization
  • • Complete prohibition of shell interpolation (sh -c)
  • • Profile whitelisting against active Hermes roster
  • • Access-code auth and x-ruang-request CSRF defense

Bidirectional Synchronization

  • • Server cache eviction on taskboard and runtime sources
  • • Immediate ?fresh=1 client re-fetch on HTTP 201
  • • Live office mapping: ready -> running -> Working desk
  • • Stacked avatar badges and speech bubbles in 2D & 3D

Accessibility & UX

  • • Accessible focus trap within OfficeDetail modal
  • • Esc dismissal restores focus to station button
  • • Double-click submission prevention via aria-busy
  • • High-contrast feedback for loading, success & errors
